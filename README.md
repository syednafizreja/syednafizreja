## Still open

- Temperature and a third dimension on the NiTi return map, and a fatigue count that lasts past one earthquake.
- A shell analysis that keeps the dent. The mode-1 imperfection already cuts the thickness gain from 25.74% to 15.03%, and the model is still elastic.
- A frame light enough that the carbon saved on the floor is still there after the earthquake. The median saving is 5.7% on 32 of 33 frames. The devices cost 620.9 kgCO2e.
